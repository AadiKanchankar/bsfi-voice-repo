## Pune branches

The Nigdi branch is at Sector 26, Pradhikaran, Nigdi, Pune 411044, and its IFSC
code is DEMO0001234. The Kothrud branch is at Paud Road, Kothrud, Pune 411038,
and its IFSC code is DEMO0001235. The Hadapsar branch is at Magarpatta Road,
Hadapsar, Pune 411028, and its IFSC code is DEMO0001236.

## Mumbai and Nashik branches

The Andheri East branch is at Chakala, Andheri East, Mumbai 400099, with IFSC
code DEMO0002101. The Nashik Road branch is at Jail Road, Nashik Road, Nashik
422101, with IFSC code DEMO0003301.

## Branch timings

Branches are open from 10:00 to 16:00 on Monday to Friday and from 10:00 to
13:30 on the first, third and fifth Saturday of the month. Branches are closed
on the second and fourth Saturday, on Sunday and on declared public holidays.
